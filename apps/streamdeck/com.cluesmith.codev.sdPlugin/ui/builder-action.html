Each Builder Action key is one slot in a window onto the fleet, sized to how many of these keys you place: the leftmost (top row first) shows the first builder, the next shows the second, and so on, and the Select dial scrolls the window when there are more builders than keys. Just place as many as you like — no slot numbers to set. Press selects that builder; on Automatic it opens the artifact for its current phase (spec / plan / diff), re-openable every press. Pick a fixed verb to always run that instead.
