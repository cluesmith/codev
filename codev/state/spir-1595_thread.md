## Phase 4: Tower agent liveness (implemented)
- `agent-state/liveness.ts`: `AgentLivenessTracker` sweeps every 5 s with one `listProcessCensus()` per sweep; walks shellper → loop → agent (builders) / shellper → agent (architects); not alive on no session, exited session, or architect restart wait. Not-alive published after 2 consecutive sweeps; failed census or unrecognized pid publishes `alive: null` without advancing the counter. Agents start `null` until their first decisive sweep.
